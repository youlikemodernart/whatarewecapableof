PiOp Minimal is a portable, curated setup for Pi, the agent runtime.[1] It gives a recipient a dependable way to use Pi for real work across files, terminal, public web, models, skills, and delegation while keeping authority, privacy, and recovery explicit. "Minimal" describes the delivery model: ordinary Pi packages, portable files, a Recipient Profile, and a small bootstrap, rather than a custom installer.[2]

PiOp knows which capabilities are present, what it must ask before doing, where work belongs, and how to leave a recovery path. It installs nothing from this page; it explains what an installation can include and prepares a reviewed request.

Overview [request]

A capable Pi setup accumulates useful operating behavior across instructions, skills, extensions, helper tools, profiles, model access, and recovery knowledge. Without a product layer, that setup is hard to transfer and support. PiOp turns the accepted parts into one understandable, recipient-ready product with one source of truth.[2]

Honest capability states are load-bearing: known, installed, configured, authenticated, available, verified, and ready are different. This page can explain a supported tool; it does not imply the tool is installed or ready.

Foundation [edit]

The Foundation is designed for ordinary terminal use. It does not depend on a particular model provider, browser, terminal application, device, or account.[2]

Skills [edit]

Skills add focused methods for particular kinds of work. They travel with an installation without becoming part of the universal baseline. Risk tiers run T0 (text-only) to T3 (can touch accounts, credentials, or live services); scope is global or project-local. Assemble a set, then generate a reviewed request. Nothing installs from this page.

Collaborator basics v0.1.1 · T0 · Global

Neutral first-use checks and private-safe source-note intake for collaborators beginning to use Pi skill packs.

Relational intelligence v0.1.0 · T0 · Global

Agency-preserving relational and introspective reflection with explicit memory, privacy, role, safety, and repair boundaries.

Brand strategy v0.1.1 · T0 · Global

Evidence-grounded brand and marketing strategy for positioning, category, messaging, architecture, and execution briefs. Plans only; never executes live actions.

Are.na v0.1.0 · T3 · Project-local

Clean-room Are.na discovery and inspection plus approval-gated creation, upload, connection, and deletion through the official CLI.

Dual harness v0.3.0 · T2 · Global

Generalized Pi and Claude Code operating layer with a neutral kernel, optional mirrors, private file-prompt bridges, and MCP partitioning guidance.

Delivery [edit]

Private GitHub is the source authority: it holds source history, exact versions, tests, and reproducible release evidence. Recipient delivery is separate.[2]

  • Choose a skill set and send the generated request.
  • We review package compatibility, scope, and risk before fulfillment.
  • If approved, we prepare a recipient-specific ZIP and share only that file through private Google Drive.
  • The delivery email includes the exact copy-and-paste Pi setup prompt.

BoundaryA GitHub account is not required for delivery. Sends, deployments, credentials, and account changes keep their own approval boundaries.
