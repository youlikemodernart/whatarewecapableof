PIOP / CURRENT STABLE STACK

A personal operating layer for Pi.

PiOp gives Pi a small operating method, explicit approval boundaries, and a library of focused skills. It is built for work that should remain understandable, removable, and under the user's control.

Skills Library

4 PACKAGES / 6 SKILLS

Each package has a declared purpose, installation scope, risk tier, and exact version. The library explains what a skill can read or change before someone decides to install it.

T0 packages contain text-only skills and prompts. T3 packages can involve accounts, credentials, live services, or writes and remain project local. Global installs apply across Pi; project-local installs stay with one workspace.

ACCESS BY INVITATION

This page is public. The source repositories remain private. GitHub decides whether a repository opens based on the signed-in account and its accepted invitation.

  • Approved collaborators can open a repository and install its pinned release.
  • Pending collaborators need to accept the GitHub invitation first.
  • Other visitors can understand the skill here while the source remains gated.

Repository access is granted manually. Payment does not grant access or change repository permissions.
