How access works

SOURCE ACCESS

This page is public; the source repositories are private. Whether a repository opens depends on your signed-in GitHub account and the invitation it has accepted.

  • Approved collaborators can open the repository and install the pinned release.
  • Pending collaborators need to accept the GitHub invitation first.
  • Everyone else can read what each package does here; the source stays private.

Access is granted manually, by invitation. Payment does not grant access or change repository permissions.
