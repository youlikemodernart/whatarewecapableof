PIOP / PRIVATE OVERVIEW

A dependable setup for Pi.

PiOp gives Pi a stable starting point for real work: useful context, explicit authority, capability discovery, and a recovery path. PiOp Minimal is the portable delivery model. Foundation is the shared baseline. Modules are selected additions.

Foundation and Modules describe product placement. Skills, extensions, commands, profiles, and prompts describe what Pi receives.

Foundation

SHARED BASELINE

Foundation is the part every PiOp installation can rely on. It works in an ordinary terminal and does not require a particular model provider, browser, terminal application, device, or account.

  • Know the installation. Report the active profile, installed capabilities, known tools, readiness limits, and current authority.
  • Find a method for the work. Route ordinary requests into focused skills, model choices, collaborators, and delegated work.
  • Preserve authority and continuity. Protect sensitive surfaces, keep consequential actions explicit, and carry sustained work through checkpoints.
  • Leave a way back. Preserve recipient-owned state and keep installation, removal, and recovery legible.

IS Terminal

RECOMMENDED MACOS HOST

IS is the native macOS vehicle for using Pi and PiOp as a persistent working environment.

It gives agent work a place to live: native windows, tabs and panes; restorable workspaces; terminal-session continuity; interface scaling; and visible, resumable Agent Workspaces. Pi remains the agent runtime. PiOp supplies the curated setup, methods, context, and authority boundaries.

IS
The macOS interface and workspace host.
Pi
The agent runtime that reads, reasons, uses tools, and acts.
PiOp
The portable, curated setup that helps Pi work dependably with a recipient.

Current release: IS 0.1.7.14 for Apple silicon and macOS 14 or newer. The app is Developer ID signed, notarized, and stapled. IS is recommended for the fullest macOS experience, but PiOp Foundation continues to work in an ordinary terminal.

Skills Library

GRAPH-DRIVEN / REVIEWED BUNDLES

PiOp selects skills from its reviewed capability graph according to what a recipient needs. A selected skill brings its required methods and bounded runtime resources into that recipient's bundle.

The graph describes skill identities and relationships. It does not install anything, grant account access, select a profile, or authorize an external action.

Tell us the outcome you need and the context in which Pi will work. We review the smallest useful skill set, its required closures, scope, and risk before preparing a recipient-specific bundle.

How delivery works

PRIVATE FULFILLMENT

The accepted PiOp source and skill graph govern what can enter a recipient bundle. Recipient delivery is separate.

  • Describe the outcome, recipient, and relevant working context.
  • We select and review the smallest useful skill set, required closures, scope, and risk.
  • If approved, we prepare a recipient-specific ZIP and share only that file through private Google Drive.
  • The delivery email includes the exact copy-and-paste Pi setup prompt.

A GitHub account is not required for recipient delivery. Payment does not change fulfillment priority, package access, or repository permissions.
